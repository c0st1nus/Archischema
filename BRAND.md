## Typography

- Display + body: `Inter`, `InterVariable`, system sans.
- Mono: `JetBrains Mono`, `IBM Plex Mono`, system monospace.
- Type scale: display 28/600, h1 20/600, h2 15/600, body 13/400, caption 11/500, mono 12/500, micro 10/600.

Use `font-feature-settings: "cv11", "ss01", "ss03"` and `font-variant-numeric: tabular-nums` for changing numbers.

## Components

- Buttons use `--primary`, `--primary-soft`, `--border`, and `--card`; keep focus rings visible through `--ring`.
- Badges use compact labels such as `PK`, `FK`, `NN`, `UQ`, plus neutral chips for dialect/status metadata.
- Surfaces use `--card` or `--card-elev`, never ad hoc background colors.
- Canvas-specific drawing uses `--canvas`, `--canvas-2`, `--grid`, `--relation`, and `--relation-selected`.
- Presence colors are fixed tokens: `--presence-alice`, `--presence-bob`, `--presence-constantine`.

## Gradients

No brand gradients. The design is technical and minimal; gradients should stay limited to subtle local effects already present in CSS.

## Tone And Voice

Use direct, specific, number-forward copy. Prefer short labels and verbs that describe the action: `Generate SQL`, `Inspect table`, `Apply changes`, `Join room`.

Avoid hype copy such as `revolutionary`, `unlock`, `supercharge`, `seamless`, and exclamation marks. Avoid decorative metaphors in product UI.

Voice example: `12 tables. 48 columns. 0 validation errors.`

## Usage

Do:

- Use the semantic CSS variables from `style/input.css` in UI code.
- Keep the dark-first IDE density and 13 px base UI text.
- Use `font-mono tabular-nums` for counts, coordinates, versions, and SQL metadata.
- Keep disabled reference-only features visibly disabled rather than hidden.
- Test both `.theme-dark` and `.theme-light` when changing shared surfaces.

Don't:

- Hardcode hex colors in component files.
- Add a second theme system.
- Override relationship colors outside the existing relation SVG layers unless only styling is intended.
- Use `transition: all`; transition named properties only.
- Expand persisted schema/domain/protocol fields to satisfy visual-only design details.
